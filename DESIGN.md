# Bulls and Cows — проектные решения

Обозначения: **L** — длина секрета (2–6), **B** — основание системы счисления (2, 8, 10 или 16).

## 1. Структуры данных и алгоритмы

### Состояние игры

`GameState` (`src/core/types.ts`) — обычный неизменяемый объект:

| Поле                      | Тип                        | Почему так                                                                         |
| ------------------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| `settings`                | `{ length, base }`         | фиксируются на весь раунд                                                          |
| `secret`                  | `string`                   | строка сохраняет ведущий ноль (`'0123'`), а `Number('0123')` его потеряет          |
| `history`                 | `readonly HistoryEntry[]`  | массив хранит порядок попыток; `readonly` запрещает `push` ещё на этапе компиляции |
| `status`                  | `'playing' \| 'won'`       | union-тип вместо двух булевых флагов: невозможное состояние просто нельзя записать |
| `startedAt`, `finishedAt` | `number`, `number \| null` | время передаётся из интерфейса, поэтому ядро остаётся чистым                       |

Состояние меняется только через `applyGuess` (`src/core/game-state.ts`), и эта функция возвращает **новый** объект:
`{ ...state, history: [...state.history, entry] }`. Старые записи переиспользуются и никогда не меняются.
Если попытка невалидна, повторяется или игра уже окончена, возвращается тот же объект, поэтому интерфейс
может сравнивать ссылки.

История хранится от старых попыток к новым, а на экране игры показывается **от новых к старым**: последний ответ
всегда сразу под полем ввода. `createHistory` (`src/ui/game-view.ts`) сначала нумерует строки через `map`,
а потом вызывает `toReversed()`. Этот метод возвращает новый массив и не трогает состояние. Атрибут
`<ol reversed>` сохраняет правильную нумерацию для скринридеров.

### Рекорды

Рекорды хранятся в `localStorage` отдельной таблицей топ-10 для каждой комбинации длины и системы счисления
(ключ вида `bulls-and-cows:records:4-10`, его строит `getRecordsKey`). Задание разрешает либо отдельные таблицы,
либо один общий список с подписью настроек у каждой записи. Выбраны отдельные таблицы, потому что результаты
в разных режимах несравнимы: в bin с длиной 2 всего 2 возможных секрета, а в hex с длиной 6 их 5 765 760.
Общий список заняли бы результаты самого лёгкого режима.

`addRecord` создаёт новый массив, сортирует его через `compareRecords` (сначала по числу попыток, при равенстве
по времени) и оставляет первые `RECORDS_LIMIT` записей. Место нового рекорда находится через `indexOf`
в этом массиве.

Надгробие с рекордами всегда показывает таблицу для **выбранных сейчас** настроек.

### Сохранённые настройки

Последние выбранные настройки хранятся под ключом `bulls-and-cows:settings`, поэтому после перезагрузки
игрок видит тот же режим и его таблицу рекордов. Если ничего не сохранено, `loadSettings` (`src/ui/storage.ts`)
возвращает настройки по умолчанию (`4 · dec`).

Данным из `localStorage` доверять нельзя: они могут быть повреждены или изменены через DevTools. Каждое чтение
идёт через `readJson` (`JSON.parse` внутри `try/catch`) и type guard: `isGameRecord` для рекордов,
`isGameSettings` для настроек (известная система счисления и длина 2–6, допустимая для неё). Некорректные
данные игнорируются и не ломают игру.

### `evaluateGuess` (`src/core/evaluate.ts`)

1. Обе строки превращаются в массивы цифр в нижнем регистре (`toDigits`), поэтому в hex `A` и `a` равны.
2. Из цифр секрета строится `Set`.
3. `bulls` = `guessDigits.filter((digit, index) => digit === secretDigits[index]).length`.
4. `matches` = `guessDigits.filter((digit) => secretSet.has(digit)).length`.
5. `cows` = `matches − bulls`. Это верно, потому что цифры в секрете и в валидной попытке уникальны.

### `countPossibleSecrets` (`src/core/count.ts`)

Количество секретов равно числу размещений без повторений:
`P(B, L) = B · (B − 1) · … · (B − L + 1)`. Оно считается рекурсивно:
`count(L, B) = B · count(L − 1, B − 1)`, базовые случаи `count(0, B) = 1` и `count(L, 0) = 0`.
Функция обёрнута в `memoize` (`src/core/memoize.ts`), а рекурсивный вызов идёт через мемоизированную версию,
поэтому в кэш попадают и все промежуточные результаты (`4|10`, `3|9`, …).

Экран настроек перерисовывается при каждом клике по чипу и каждый раз вызывает `countPossibleSecrets`.
Возврат к уже показанной комбинации стоит одного поиска в `Map`.

### `generateSecret` (`src/core/secret.ts`)

Рекурсивный выбор без мутаций: берётся случайный индекс в пуле доступных цифр, затем рекурсивно выбираются
`L − 1` цифр из нового пула без выбранной (`pool.filter`). Источник случайности передаётся параметром
(`random = Math.random`), поэтому тесты подставляют предсказуемую функцию.

## 2. Сложность

| Функция                | Время                                | Память | Почему                                                                                                                                                              |
| ---------------------- | ------------------------------------ | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generateSecret`       | O(L·B)                               | O(L·B) | L шагов рекурсии; на каждом шаге пул копируется через `filter` (≤ B элементов) и результат собирается через spread (≤ L элементов). Глубина рекурсии L              |
| `evaluateGuess`        | O(L)                                 | O(L)   | `split`/`map`, построение `Set` и два прохода `filter` линейны; `Set.has` в среднем O(1). С `includes` вместо `Set` было бы O(L²)                                   |
| `isValidGuess`         | O(L·B)                               | O(L)   | создание валидатора копирует алфавит (O(B)); `every` вызывает `alphabet.includes` (O(B)) для каждого из L символов; проверка уникальности через `Set` занимает O(L) |
| `countPossibleSecrets` | O(L) при первом вызове, O(1) из кэша | O(L)   | первый вызов делает L рекурсивных вызовов (глубина стека L) и кладёт L значений в кэш; повторный вызов — один поиск в `Map`                                         |

Все размеры крошечные (L ≤ 6, B ≤ 16), поэтому любая функция работает мгновенно. Таблица показывает,
как они масштабировались бы на больших данных.

## 3. Принципы чистого кода

| Принцип                                        | Где                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Чистые функции без побочных эффектов           | весь `src/core/*`; `Date.now()` и `Math.random` передаются параметрами (`applyGuess(state, guess, now)`, `generateSecret(..., random)`)                                                                                                                                                    |
| Единственная ответственность, разделение слоёв | `src/core` — правила игры; `src/ui/*-view.ts` — только разметка, по одной части экрана в файле (`settings-view`, `game-view`, `records-view`, `stats-view`, `win-view`); `src/ui/storage.ts` — только хранилище; `src/ui/images.ts` — пути к ассетам в одном месте; `src/main.ts` — связка |
| DRY                                            | `createDigitValidator` переиспользуется в `isValidGuess` и `sanitizeGuess`; `normalizeDigit` — единственное место с правилом регистра для hex; `readJson` / `writeJson` — единственный доступ к `localStorage` и обработка его ошибок                                                      |
| Понятные имена                                 | `isRepeatedGuess`, `pickUniqueDigits`, `compareRecords`, `canAcceptGuess` читаются как фразы; булевы значения начинаются с `is`/`can`/`has`                                                                                                                                                |
| Нет магических чисел                           | `MIN_LENGTH`, `MAX_LENGTH`, `RECORDS_LIMIT`, `ALL_DIGITS` в `src/core/constants.ts`; `TICK_MS` и `DEFAULT_SETTINGS` в `src/main.ts`; `MASCOT_SIZES` в `src/ui/images.ts`; цвета и размеры — CSS-переменные (дизайн-токены) в `:root` файла `public/styles.css`                             |
| Маленькие функции                              | большинство функций занимает 1–10 строк; `applyGuess` разбита на `canAcceptGuess` и построение нового состояния                                                                                                                                                                            |
| Ранний выход (guard clauses)                   | `generateSecret` сразу бросает `RangeError`; `applyGuess` возвращается досрочно; `handleGuess` выходит при ошибке                                                                                                                                                                          |
| Неизменяемость                                 | `readonly` типы в `src/core/types.ts`; spread в `applyGuess`, `addRecord`, `changeLength`; `toReversed()` вместо `reverse()` для истории                                                                                                                                                   |
| KISS                                           | ни классов, ни фреймворков, ни бандлера: `tsc` и нативные ES-модули                                                                                                                                                                                                                        |
